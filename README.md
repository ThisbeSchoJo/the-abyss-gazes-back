# Moral Dilemma Game

A React-based single-page application (SPA) that presents users with moral dilemmas and categorizes their answers into different moral archetypes. Players can explore different dilemmas, submit their responses, and receive a profile based on their answers.

## Features:
- Moral Dilemmas: Users are presented with multiple-choice moral dilemmas.
- Moral Archetypes: Based on their answers, users are assigned one of ten archetypes, such as The Idealist, The Cynic, The Opportunist, etc.
- User Profiles: Users can enter their name and image to save their results and track their progress.
- Score Tracking: User responses are saved and reflected in their profile.
- Client-Side Routing: React Router is used to navigate between different views such as the game, user profiles, and a home page.
